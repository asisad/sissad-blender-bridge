# پل ارتباطی SiSsad برای بلندر

این پروژه یک رابط مستقل برای استفادهٔ هماهنگ از **Blender Lab MCP** و
**MCP for Blender** است. از طریق API پایتون، خط فرمان و MCP می‌توان به
بلندر فرمان داد و داده و تصویر واقعی دریافت کرد.

در آزمون ۱۱ اکتبر ۲۰۲۶، هر دو ابزار روی بلندر ۵٫۲٫۲ و ۵٫۳ بتا محلی کار کردند.
در چت وب هم ساخت مکعب و بازخوانی جداگانه از مسیر Lab روی نسخهٔ ۵٫۲ موفق بود.
[نتایج و محدودهٔ دقیق آزمون‌ها](docs/verification-2026-10-11.md) ثبت شده‌اند.

۱) هر ابزار در محیط جدا نصب می‌شود. دو نسخهٔ بلندر، پورت‌های جدا دارند.

۲) چهار پروفایل `lab52`، `community52`، `lab53` و `community53` مقصد فرمان
را مشخص می‌کنند. قفل مشترک، فراخوانی‌های همین رابط را به‌ترتیب اجرا می‌کند.

۳) کد اجرایی افزونه‌های اصلی داخل این مخزن کپی نشده است. نسخه و مجوز هرکدام
در [سوابق منابع](THIRD_PARTY_NOTICES.md) ثبت شده است.

۴) نصب افزونه به معنی تسلط آزموده‌شده بر تمام ابزارها نیست. قابلیت‌های معماری،
جواهرسازی، ریگ و آواتار و خروجی بازی باید با افزونه و نسخهٔ واقعی بررسی شوند.

برای نصب از [راهنمای ویندوز](docs/install-windows.md) استفاده کنید. فرمان‌های
API و CLI در [راهنمای اصلی](README.md) و محدودیت‌ها در [سند امنیت](SECURITY.md) هستند.

اتصال وب، علاوه بر اتصال محلی، به تونل اختصاصی، کلید اجرایی و اتصال افزونه در
حساب ChatGPT نیاز دارد. نصب محلی را نباید «اتصال وب تکمیل شد» گزارش کرد.

تمام آزمایش‌های تغییردهنده باید روی صحنهٔ آزمایشی اجرا شوند. مسیر اجرای Python
با مجوز مشخص کاربر در همین پروژه فعال است و محدودیت‌های پروژهٔ اسکچاپ را تغییر نمی‌دهد.
